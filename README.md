# SVG 转 PNG 工具

一个纯前端、单文件的 SVG 转 PNG 网页工具。粘贴或拖入 SVG 即可实时预览,按需缩放、设置背景色后导出为 PNG。

- **零依赖**:单个 `index.html`,无任何外部库、无构建步骤
- **本地处理**:所有转换都在浏览器内完成,文件不会上传到任何服务器
- **隐私安全**:可完全离线使用

## 使用方法

### 方式一:直接打开(离线)

双击 `index.html`,在浏览器中打开即可使用。

> 注意:直接以 `file://` 协议打开时,「复制到剪贴板」功能可能受浏览器安全策略限制而不可用,此时请改用「下载 PNG」。

### 方式二:本地服务器

在项目目录下启动任意静态服务器,例如:

```bash
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000>。

## 加载 SVG

支持三种方式,可任选其一:

1. **拖拽**:将 `.svg` 文件拖入左侧「拖入 `.svg` 文件」区域
2. **选择文件**:点击拖拽区域,在文件选择器中选取 `.svg` 文件
3. **粘贴源码**:直接在下方代码框中粘贴 SVG 源码

加载后左侧会实时显示 SVG 预览及其原始尺寸。

## 转换与导出

1. 在「缩放」或「输出尺寸」中设置目标尺寸(可二者任选,详见下文)
2. 在「背景」中选择「透明」或指定纯色背景
3. 点击 **转换为 PNG**,右侧显示转换结果、输出尺寸与文件大小
4. 通过以下任一方式保存:
   - **下载 PNG**:按浏览器下载设置保存文件
   - **复制到剪贴板**:将 PNG 图片复制,可直接粘贴到聊天窗口、图片编辑器等(需浏览器支持)

## 尺寸控制

| 控件 | 作用 |
| --- | --- |
| 输出尺寸(勾选) | 指定固定的输出宽高;只填宽或高时,另一侧按原图比例自动计算 |
| 缩放 | 以原始尺寸为基准整体放大/缩小,范围 0.2× – 8× |
| 背景 | 「透明」保留 alpha 通道;「颜色」可为输出填充任意纯色背景 |

勾选「输出尺寸」后,宽度、高度会随缩放滑块联动刷新,可再手动覆盖。

## 技术说明

- 使用 `DOMParser` 校验并解析 SVG,自动补全缺失的 `width`/`height`(从 `viewBox` 推断),保证仅含 `viewBox` 的 SVG 也能正确渲染
- 通过 `data:` URL 载入 SVG,用 `<canvas>` 2D 上下文绘制后以 `canvas.toBlob()` 导出 PNG
- 输出文件命名:下载的文件名为 `output_宽x高.png`
- 转换失败(如 SVG 含跨域外部图片)时,会给出明确的中文错误提示

## 浏览器兼容性

需要现代浏览器支持:`Canvas 2D`、`<img>.decode()`、`fetch`、`URL.createObjectURL` 与 `navigator.clipboard`。

- 推荐:最新版 Chrome / Edge / Firefox / Safari
- 「复制到剪贴板」需要 HTTPS 或 `localhost` 环境,且浏览器支持 `ClipboardItem`
